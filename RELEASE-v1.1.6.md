# IVM Optim v1.1.6 — Machine Logs CSV compatibility

- Supports Date & Time,Action CSV without Location/Machine columns.
- Requires explicit machine mapping for machine-less reports.
- Accepts 2/4-digit years, 12/24-hour clock.
- Stable import keys for repeat uploads (row-position-aware keys preserve repeated identical events within a file).
- Adds CSV template.
- No database migration.
